{% include section_intro.html title="オープンソースのSysML v2モデリングツール" desc="

SysONは、SysML v2モデルを作成・編集するための、オープンソースのWebベースMBSEツールです。

これは、グラフィカルなモデリング、標準に基づいた相互運用性、そしてシステムエンジニアリングのための柔軟な環境を組み合わせたものです。

{% include block_heading.html title="の概要" %}

オープンソースの Web ベースの MBSE モデリング ツールである SysON を使用して、
SysML v2 モデルをグラフィカルに編集します。
